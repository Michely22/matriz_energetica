📋 Descripción

Esta aplicación interactiva de análisis de datos energéticos ha sido desarrollada como parte del curso de Análisis de Datos de Talento Tech. La herramienta te permite explorar y visualizar datos detallados de generación de energía renovable, incluyendo solar, eólica, hídrica y geotérmica, cubriendo el período desde 2020 hasta 2026. ¡Obtén perspectivas valiosas sobre la transición energética!

🛠️ Instalación y Uso

Sigue estos sencillos pasos para empezar a explorar los datos energéticos:

  1. Clona el repositorio en tu máquina local: 
    git clone <repository-url>
  2. Navega al directorio del proyecto: 
    cd energy-analysis
  3. (Opcional pero recomendado) Crea y activa un entorno virtual: 
    python -m venv venv
# En Windows:
venv\Scripts\activate
# En macOS/Linux:
source venv/bin/activate
  4. Instala las dependencias necesarias: 
    pip install -r requirements.txt
  5. Ejecuta la aplicación de Streamlit: 
    streamlit run app.py
  6. ¡Listo! La aplicación se abrirá automáticamente en tu navegador predeterminado.
